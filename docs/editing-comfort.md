# 编辑体验实现说明

更新日期：2026-09-19。

## 已实现的行为

- 新笔迹以中点二次曲线平滑，保留起止位置，支持点画。旧作品保留原始折线。
- 画布按约 16ms 合并重绘请求，避免半透明笔迹反复叠画变深；图片解码请求复用，平滑几何按路径点缓存。
- 橡皮切割实际笔迹，尺寸为 8～80 个画布像素，露出底下的图片和画布。快速移动通过连续扫过的区域计算，不依赖触摸点刚好落在笔迹上。
- 选择笔迹时按实际线条命中，图片按矩形命中。选中后显示删除按钮；移动、删除、擦除、插图、绘画与清空均支持撤销和重做。
- 当前编辑会话最多记录 60 步。一次连续触摸是一步；新编辑清除重做，单纯选中和视图手势不清除。新建、切换作品和重新启动会重置历史。
- 操作栏使用 Photoshop 风格的“还原 / 重做”：还原撤回刚刚的操作，重做重新执行刚刚还原的操作。
- 画布将 `touchend` 与 `touchcancel` 分开处理。取消事件不使用 `changedTouches` 补点；iPhone 左边缘向右滑触发的返回手势会取消当前手势并恢复到开始前状态。
- 停止操作约 1 秒自动保存当前草稿，切后台和页面退出时补存。恢复工具、颜色、视图、作品关联与内容；自动恢复不消耗文件额度，也不直接更新作品列表。
- 顶部操作栏显示还原／重做与草稿状态。擦除面板说明其作用范围；帮助同步更新。

## 数据与绘制

`utils/strokeGeometry.js` 提供平滑路径、绘制、命中检测和擦除。新路径增加 `smooth: true`；擦除后的片段固化为线段，避免对剩余笔迹再次平滑造成变形。原有 `type: path/image` 数据格式保持兼容。

擦除按触摸线段扫过的圆形区域求交，额外计入笔迹半宽。仅修改命中的笔迹对象，图片不变，片段维持原有位置与层级。旧版本留下的白色路径不能可靠区分橡皮和白色画笔，因此不自动迁移。

画板显示、画板导出、缩略图和作品页导出共享笔迹绘制函数。导出隐藏选择框。单点路径以圆点绘制。

`utils/editHistory.js` 保存对象列表和画布边界／视图状态的前后快照。完成操作后的对象保持不可变，共享未变化的路径数据，避免每次操作复制所有点。移动创建新对象；擦除创建新片段。

## 草稿与保存安全

`utils/draftStore.js` 在小程序用户文件目录写入 `note-paint-draft.json`。先写临时文件再替换，写入或替换失败时保留上一份有效草稿，界面提示手动保存。

清理草稿先写作废标记，再尝试删除文件；文件写入失败时用小容量存储记录被作废的草稿标识。两条失效路径均失败时保留当前画板并提示，避免用户确认新建后旧草稿意外复活。

`utils/boardData.js` 验证恢复对象，补齐边界并剔除损坏对象／缺失图片，保留仍然有效的笔迹，向用户提示部分内容无法恢复。

手动保存先固定内容快照。缩略图生成期间产生的新修改不会被误标为已保存；切到其他画板后，旧保存与图片插入回调不能修改新画板。保存和导出共用离屏画布，互斥执行。

草稿只保留当前画板一份。要保留多份作品仍需手动保存；用户确认放弃修改后清除该草稿。成功手动保存且没有新增修改时清理恢复草稿。空白修改也可以恢复，例如用户擦除了已保存作品的全部笔迹。

图片插入前必须持久化成功，失败不插入可能过期的临时图片。内容仍仅在当前设备保存，不提供云同步。
