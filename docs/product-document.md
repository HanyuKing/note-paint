# 笔记画板产品文档

## 1. 产品概述

笔记画板是一款基于微信小程序 Canvas 能力实现的轻量级手绘与批注工具。产品面向需要随手记录、绘制草图、插入图片并进行简单标注的用户，提供画笔、橡皮、颜色、粗细、图片插入、对象选择、画布缩放平移、撤销、清空和保存到相册等核心能力。

当前项目为单页面小程序，页面标题为“笔记画板”，入口页面为 `page/component/jdraw/jdraw`。产品不依赖后端服务，主要数据在页面内存中维护，导出时通过小程序相册能力保存为图片。

## 2. 目标用户

- 需要快速记录灵感、草图、手写内容的个人用户。
- 需要在图片上做简单圈画、批注和说明的用户。
- 需要在移动端完成白板式自由绘制的用户。
- 需要保存绘制结果到手机相册，便于分享或留档的用户。

## 3. 使用场景

### 3.1 随手绘制笔记

用户打开小程序后直接进入画布，可以选择画笔颜色和粗细，在画布上单指绘制手写文字、线条、结构图或草图。

### 3.2 图片批注

用户点击图片工具，从相册或相机选择一张图片插入画布，然后通过画笔在图片上进行标注，或在选择模式下拖动图片位置。

### 3.3 大画布记录

用户可以使用双指缩放和平移视图。当绘制内容超出初始画布范围时，系统会动态扩展画布边界，支持更大范围的自由创作。

### 3.4 作品保存

用户完成绘制后点击保存按钮，系统将完整画布内容导出为 PNG 图片，并保存到手机相册。

## 4. 产品定位

笔记画板定位为“移动端轻量白板工具”，强调打开即用、操作直观、无需登录、无需网络后台。相比复杂绘图软件，本产品优先满足快速记录和基础批注，不追求图层管理、矢量编辑、多人协作等高级能力。

## 5. 核心功能

### 5.1 绘画工具

用户可以在绘画模式下使用单指在画布上绘制线条。

- 默认画笔颜色为黑色。
- 支持从预置色板中选择颜色。
- 支持通过滑块调整画笔粗细，范围为 1 到 10。
- 绘制过程中线条使用圆角端点和圆角连接，提升手写观感。

### 5.2 橡皮工具

用户可以切换到橡皮工具进行擦除。当前实现中，橡皮本质上是一支白色、固定较粗宽度的画笔，覆盖已有内容以达到擦除效果。

### 5.3 颜色选择

页面提供横向滚动色板，用户点击色块即可切换画笔颜色。选择颜色时会自动回到画笔模式。

### 5.4 画笔粗细调整

页面提供滑块控制当前画笔粗细。调整后的粗细会应用于后续新绘制的路径。

### 5.5 选择模式

用户点击选择工具后进入选择模式。

- 点击已有对象会选中该对象。
- 被选中的对象会显示绿色选中框。
- 拖动选中对象可以移动对象位置。
- 点击空白区域并拖动可以平移画布视图。

当前可选择对象包括手绘路径和插入图片。

### 5.6 插入图片

用户点击图片工具后，可以从相册或相机选择一张图片插入画布。

- 每次插入一张图片。
- 图片默认以宽度 200px 显示，并按原始宽高比计算高度。
- 图片默认插入到当前屏幕中心对应的画布坐标位置。
- 插入图片会自动扩展画布边界，确保导出时包含图片内容。

### 5.7 缩放和平移

用户可以通过双指手势缩放画布，并在缩放过程中移动视口。

- 缩放以双指中心点为视觉中心。
- 最小缩放比例限制为 5%。
- 缩放时会显示当前缩放百分比。
- 在选择模式下，点击空白区域拖动可进行单指平移。

### 5.8 动态画布扩展

当用户绘制或插入图片超出当前画布边界时，系统会自动扩展画布边界，并更新画布宽高。扩展时会额外保留一定留白，避免内容紧贴边缘。

### 5.9 撤销

用户点击撤销按钮后，系统会移除最近一次创建的画布对象。

当前撤销粒度为对象级：

- 一整条连续绘制路径视为一个对象。
- 一张插入图片视为一个对象。
- 不支持逐点撤销，也不支持恢复。

### 5.10 清空

用户点击清空按钮后，系统会清除所有画布对象，并重置画布边界、画布尺寸、缩放比例和平移位置。

### 5.11 保存到相册

用户点击保存按钮后，系统会将完整画布内容导出为 PNG 图片并保存到手机相册。

- 导出范围基于当前画布边界计算，而不是仅导出屏幕可见区域。
- 导出时使用离屏 Canvas，避免破坏主画布当前视图状态。
- 保存相册需要用户授权 `scope.writePhotosAlbum`。
- 如果保存失败且与权限有关，会引导用户打开设置页授权。

### 5.12 使用说明

首次打开小程序时，系统会展示操作指南弹窗。弹窗关闭后，后续默认不再自动显示。用户也可以通过顶部“使用说明”按钮再次打开。

### 5.13 广告位

页面底部集成微信小程序原生模板广告位。广告加载、错误和关闭事件均有对应监听；用户关闭广告后，本次页面状态下不再显示广告容器。

## 6. 页面结构

页面从上到下主要分为：

1. 工具栏：选择、画笔、橡皮、插入图片、清空、撤销、保存、使用说明。
2. 颜色栏：横向滚动色板。
3. 粗细滑块：调整画笔尺寸。
4. 画布区域：承载绘制、图片、缩放提示。
5. 底部广告：固定在页面底部。
6. 使用说明弹窗：首次使用或用户手动打开时展示。

## 7. 交互说明

### 7.1 绘制流程

1. 用户选择画笔或颜色。
2. 用户在画布上单指按下并移动。
3. 系统记录触摸点，生成路径对象。
4. 移动过程中增量绘制线条。
5. 手指抬起后结束本次路径。

### 7.2 选择和拖动流程

1. 用户点击选择工具。
2. 用户点击画布对象。
3. 系统根据对象包围盒做命中检测。
4. 命中后显示选中框。
5. 用户拖动时，系统按照当前缩放比例换算位移并更新对象坐标。

### 7.3 双指缩放流程

1. 用户双指触摸画布。
2. 系统记录初始双指距离和中心点。
3. 双指移动时，系统计算距离变化得到缩放比例。
4. 系统同步更新视图平移量，使缩放围绕双指中心进行。
5. 缩放过程中显示百分比提示。

### 7.4 保存流程

1. 用户点击保存按钮。
2. 系统根据画布边界计算完整导出尺寸。
3. 系统创建并绘制离屏 Canvas。
4. 系统调用 `wx.canvasToTempFilePath` 生成临时 PNG 文件。
5. 系统调用 `wx.saveImageToPhotosAlbum` 保存到相册。
6. 成功时提示“保存成功”，失败时提示错误或引导授权。

## 8. 权限和隐私

产品保存作品到相册时需要申请写入相册权限。权限说明文案配置为“您的作品将保存到手机相册”。

当前项目没有上传用户作品、账号登录、远程同步或后端存储能力。`app.js` 中保留了微信登录示例代码，但当前页面功能未使用登录态。

## 9. 当前边界

- 不支持多页面管理。
- 不支持作品草稿持久化，退出页面后画布对象不会自动恢复。
- 不支持图层面板、对象缩放、对象旋转、对象删除等高级编辑能力。
- 不支持重做。
- 橡皮是白色覆盖式擦除，不是真正删除底层路径片段。
- 导出图片会包含所有画布对象，但当前绘制函数没有专门隐藏选中框的导出参数；如果保存时有对象被选中，可能需要进一步确认导出效果是否符合预期。

## 10. 后续优化建议

- 增加草稿自动保存和恢复能力。
- 增加重做、对象删除、对象缩放和对象旋转。
- 将橡皮升级为路径级或像素级真实擦除。
- 导出时明确隐藏选中框和交互辅助元素。
- 增加图片对象尺寸调整能力。
- 增加页面内保存前预览。
- 优化大对象数量下的渲染性能和内存占用。
