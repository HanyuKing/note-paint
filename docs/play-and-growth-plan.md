# 笔记画板：玩法与用户增长规划

日期：2026-09-19。

方向：暂缓商业化，先丰富能让人愿意尝试、完成作品、分享和再次使用的功能。本文是规划，列出的新增功能尚未实施；招募、发布和传播也尚未执行。

## 1. 这一阶段要验证什么

让不擅长画画的人，也能在两分钟内做出一张有意思的图。

首批尝试用户聚焦于喜欢轻松涂鸦、表情创作和朋友间互动的人。从熟人和兴趣圈收集反馈，不把专业绘画需求作为首版目标。

需要逐步回答三个问题：

1. 看到一个具体玩法，用户愿不愿意点进来？
2. 点进来以后，能不能很快下笔，并完成一张图？
3. 完成后，愿不愿意展示给朋友或再玩一题？

当前已有画笔、调色、图片插入、对象移动、作品保存和图片导出，是承接玩法的基础。目前进入产品主要面对空白画布，分享入口也主要指向通用画板，缺少具体的参与理由。

## 2. 主玩法：给一笔，接着画

向用户提供少量线条或图形，让用户补成自己的作品。例如：

- 一个圆：画成今天的心情。
- 一条弯线：画成一种动物。
- 两个黑点：补成一个表情。
- 一个不规则轮廓：画成一只奇怪的小怪兽。
- 半张脸：补出另一半，可以故意画得离谱。

它的价值在于题目短、落笔容易，同一个起点可以出现许多不同答案。画得精细、画得搞笑、只有几笔，都可以成为分享的理由。

首版准备 8～12 张原创底图，每题一句提示；先选择用户容易完成的题目。底图可以用现有路径或图片能力承载，补画内容单独编辑，避免误移底图。

默认没有倒计时，也不自动结束。限时挑战在用户确实喜欢后再作为可选模式。两分钟是体验目标，不是强制规则。

### 完整参与流程

看到题目示例 → 点开同题画板 → 直接落笔 → 完成 → 生成题目与作品卡片 → 主动分享 → 朋友进入同一道题再画一版。

首版“同题挑战”让双方使用同一个内置题目，独立绘画。分享携带固定题目编号和版本，避免题库更新或日期变化后打开另一道题。

当前作品保存在本地。朋友接着编辑发送者的实际笔迹，需要另外设计作品上传与获取，属于后续的“好友接画”；首版不把同题挑战描述成这项能力。

## 3. 功能优先级

| 功能 | 用户能感受到的价值 | 相对投入 | 顺序 |
| --- | --- | --- | --- |
| 接画底图与一句话题目 | 打开就知道画什么 | 小到中 | 第一版核心 |
| 同题入口与作品分享卡 | 朋友有明确参与理由 | 中 | 第一版核心 |
| 自动草稿恢复、重做、稳定保存 | 画错能改、离开不丢 | 中 | 第一版基础 |
| 对称画笔 | 随手画几笔就有漂亮结果 | 中 | 第二版优先试验 |
| 今日题目、每周主题包 | 提供新的创作内容 | 小到中，持续维护 | 第一版先小规模轮换 |
| 表情轮廓、少量原创贴纸 | 不会画也能完成有趣作品 | 中，含素材维护 | 根据试用反馈加入 |
| 作品日历、最近创作回顾 | 看到自己的积累，再次打开有内容 | 小到中 | 出现复用后再加 |
| 逐笔展示动画 | 让创作成果更适合演示 | 中 | 后续验证 |
| 好友接着画同一张作品 | 真正的共同创作 | 大，需要作品传递 | 同题玩法被验证后评估 |

投入等级是相对估计，不能直接视为工期承诺。第一次开发只覆盖一条完整参与流程，后续玩法逐个试验。

对称画笔先做左右镜像，例如画蝴蝶、面具和小怪兽；用户喜欢后再扩展放射对称。背景纸张和画笔装饰可以改善体验，但优先级取决于是否帮助完成和展示作品。

现有橡皮采用白色覆盖。加入彩色背景或模板前，需要处理擦除规则，避免出现白色涂抹破坏底图的体验。复杂新背景不能脱离这个基础问题单独上线。

逐笔展示最终作品可以利用保存的路径，但它不等于还原完整历史。若要真实呈现移动、擦除和撤销过程，需要新增操作记录。首轮不承诺视频导出。

## 4. 入口与完成页

保持“画板 / 作品 / 我的”结构，先在画板入口提供轻量的灵感区域：

- 今日接画：展示底图缩略图、短题目和“开始画”。
- 换一道题：快速切换其他底图。
- 自由画：继续保留直接进入空白画板的入口。
- 有未完成草稿时：优先展示“继续上次”，开始新题前保留或确认处理旧稿。

首次操作用少量就地提示说明；完整使用说明保留为可主动打开的帮助。尽快让用户看到画布并下笔。

完成页先提供作品预览、保存、邀请朋友画同题、再画一题。分享卡片可以包含题目、用户作品和可选署名；成品图片与邀请卡片分开，方便用户选择。

例子：“同一个圆，我画成了熬夜的猫。你会画成什么？”

分享预览、题目参数和相册保存需真机验证。首版如果不提供作品上传，不能承诺朋友打开后能看到在线作品详情或编辑原作。

当前普通导出需要激励视频、免费文件额度只有 1。增长试验建议先取消普通导出的广告门槛并放宽保存额度，让创作到展示的流程顺畅。具体调整随玩法版本实施，本文不直接改变现有行为。分享始终由用户主动选择，不要求转发或拉人才能保存作品。

## 5. 首批用户从哪里来

### 第一轮：20～30 位真实试玩者

从朋友和已有兴趣圈开始招募。邀请内容围绕一张具体底图，例如“给你两个点，你能画成什么？”，附上两三个不同答案作为示例。

观察其自然操作，尽量不边看边指导；记录卡住的位置、是否完成、是否主动再玩。愿意发回作品时先征得同意，再用于后续展示。推广和招募由用户自行决定与执行，当前未发送消息。

### 第二轮：选择一个内容平台持续演示

先选自己熟悉的一个平台，例如小红书或视频号，每周发布 2～3 条内容：

- 同一个圆的五种脑洞。
- 随手画一边，另一边自动出现。
- 用两笔画出今天的精神状态。

以底图、绘制过程和成品为主要内容，让观众快速理解玩法。进入路径以该平台实际支持的方式安排，并验证用户能否顺利到达对应题目，不假定所有平台都支持直接跳转小程序。

内容轮换可以尝试“周一画心情、周末画小怪兽、节日画小卡片”，先准备少量题库定期发布，控制个人维护负担。

### 第三轮：让参与者带来新的同题参与者

把作品卡和同题入口连起来，分别统计不同题目和渠道带来的进入与完成。先用同题的不同答案制造讨论，积累被用户允许展示的示例。

公开作品广场、排行榜和陌生人评论留待后续评估，因为它们需要持续内容供给、维护和管理。早期先做好个人创作和朋友间自愿分享。

## 6. 开发与验证顺序

| 批次 | 交付内容 | 验证问题 |
| --- | --- | --- |
| A：让人能开始并完成 | 8～12 张接画底图、直接开始、草稿恢复、重做、免费普通导出 | 空白页障碍是否降低？能否独立完成？ |
| B：让人能邀请朋友 | 题目作品卡、固定同题入口、渠道与题目统计 | 作品有没有展示欲？朋友点进来会不会画？ |
| C：增加即时乐趣 | 左右对称画笔、小规模题目更新 | 用户是否愿意再画一张或回来尝试？ |
| D：根据证据扩展 | 从表情素材、作品回顾、逐笔展示中选一个 | 新功能是否带来更多完成和自然复用？ |

先完成 A 和 B 的最小版本，就开始试用，不必等待全部功能完成。具体时间取决于可投入工时，首轮范围按“能完成一题并邀请朋友画同题”控制。

## 7. 怎样判断玩法有效

早期重点看任务完成和自愿参与，停留时长只作为辅助信息。

| 指标 | 观察口径 | 用来判断 |
| --- | --- | --- |
| 进入后开始画 | 打开题目后产生第一笔的独立用户 / 打开题目的独立用户 | 题目是否容易理解，入口是否顺畅 |
| 开始后的完成 | 有新增内容并确认完成的独立用户 / 已开始绘制的独立用户 | 玩法难度和编辑体验是否合适 |
| 分享入口使用 | 点击邀请同题或生成分享卡的人数 / 完成用户数 | 是否产生展示意愿；不等同于实际分享成功 |
| 同题带来的参与 | 从分享入口进入后实际开始、完成的人数 | 分享有没有带来有兴趣的新参与者 |
| 再玩与复访 | 同次体验完成第二题；以及首次参与后第 2～7 天再次完成作品 | 内容是否值得继续玩和再次打开 |

开始计时与确认完成仅用于行为统计，不采集作品内容。新旧用户、题目和来源分别观察。小样本先看人数、完整体验过程和用户原话，不把比例当成确定结论。

首轮可以用“30 位受邀者中，至少 15 位独立完成，5 位主动再玩或展示作品”作为内部讨论参考。它只是初步筛选标准，受邀熟人的表现不能直接代表自然增长。

第二轮再观察陌生用户和分享进入者。如果很多人进入却没有落笔，就改题目与入口；如果画完不分享，就检查成品和邀请理由；如果朋友进入却不参与，就改同题承接；如果只玩一次，就比较题库更新和新玩法是否改善复访。

## 8. 当前建议

第一步围绕“给一笔，接着画”做完整小版本，优先补齐保存与编辑体验，再逐步加入对称画笔。

先找到一个用户能用一句话介绍给朋友的玩法，并用真实完成、同题参与和再次创作验证它。商业化路线保持暂缓，后续根据自然使用与维护成本另行讨论。
